# 订阅流程配置

2026-11-03 用户要求在新 Python 项目中保留两个 cslive 流程选项，并新增 gener提链+http直连付款流程，仅增加配置选项。

| 页面选项 | 保存值 |
| --- | --- |
| cslive 全流程 | `cslive` |
| cslive 提链 + HTTP 直连付款流程 | `cslive_direct_pay` |
| gener提链+http直连付款流程 | `gener_direct_pay` |

入口为「支付全监控 → 订阅流程配置」，或「代理管理 → 付款配置」。选择保存在 `settings.payment.subscription_flow`，沿用 `PUT /api/admin/settings/payment`。重新打开时回显已保存的选择，未配置或旧值不受支持时默认显示 cslive 全流程。

此次仅修改配置页面，不添加订阅、提链或付款执行逻辑。两个业务菜单的执行后端仍按此前要求留空。

后续配置修正：用户明确 gener_direct_pay 对应的全部套餐必须使用长链。选择该流程后，所有套餐（含预设套餐）的链接类型固定显示长链并禁用修改；后端保存配置时统一写入 hosted，旧客户端遗漏流程字段时同样执行该约束。其他流程仍可逐套餐选择长短链。用户确认先只修配置，付款保持未启用。
