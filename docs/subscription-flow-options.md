# 订阅流程配置

2026-11-03 最新本地版本仅保留 `gener_direct_pay`，显示名为 `gener提链+http直连付款流程 +Go付款成功后续`。用户撤回了新增替代流程的要求；`cslive_direct_pay` 的选项、专属接口、队列与源码已删除。

- 订阅办理和结账链接均使用原 `/api/orders` 入口。订阅继续由 gener 提链、原 HTTP 付款、独立 Go 程序完成付款成功后的处理；结账链接功能仅生成链接。
- 流程配置允许空值或 `gener_direct_pay`，套餐继续强制长链。旧客户端保存已删除的流程返回 400，旧专属接口返回 404。已有失效配置显示未连接，不自动改写成 gener。
- 受理时将流程归属和订单、冻结费用在同一事务保存；领取按订单归属，不能因为后台配置变化改派未知或已删除流程的旧单。
- 领取器保留事务锁、总并发、单用户并发、后台付款开关、调度暂停与网络重试时间限制。
- 本次没有历史订单迁移或重跑，没有清理数据库或改写业务配置，只更新本地。

配置入口及 `PUT /api/admin/settings/payment` 接口不变。Go 后续见 `go-post-payment.md`，本次删除范围和验收见 `remove-cslive-direct.md`。
