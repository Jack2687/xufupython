# 认证修复与兑换使用情况（2026-11-05）

登录、注册、重置、个人改密和发码中的同步密码计算/数据库工作移到有界线程执行，认证事务局部 lock_timeout=3s、statement_timeout=10s。登录签发会话时持锁复核密码版本、邮箱和用户状态；注册用户与首会话同事务。内部无 HTTP headers 的后台日志请求仍可记录来源。

TRUSTED_PROXIES 为逗号分隔的可信反代 IP/CIDR，默认仅 loopback，不接受 /0。只在直接对端受信任时，从右向左解析 X-Forwarded-For，遇到首个不可信地址即停止；坏头回退直接对端。生产应配置实际 Docker 网关及上游可信代理段，不能信任任意公网。

Cookie Secure 由 COOKIE_SECURE、真实 TLS、匹配的 HTTPS PUBLIC_ORIGIN 或可信直接反代的 HTTPS 头确定。登录/注册操作期间禁止切换模式或并行发码，密码输入按后端 UTF-8 字节规则验证。

兑换码管理新增独立“使用情况”，北京时间日/周/月/年、周一为周起点；支持日期导航、搜索及服务端分页。按实际 used_at 汇总次数、码数量、使用人数和入账积分，明细和汇总同只读快照；保留已删除用户的兑换历史，不返回完整码/密文，不变更兑换、账本和余额。

客户工作台和运营概览新增“敏感数据已加密保护”。接口按原管理员权限保护。
