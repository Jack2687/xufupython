# 服务费报价修复

2026-11-03 用户授权修复订阅页面“服务费报价暂时无法获取，请重试”。运行中的旧版本没有报价接口，返回 404；磁盘上后续添加的订阅模块曾包含一个尚未加载的报价实现。本次将报价独立放入会员模块，移除订阅模块的重复定义。

- `GET /api/quote?product_id=...`：登录会话访问。
- `GET /api/v1/quote?product_id=...`：沿用既有 API 密钥与登录鉴权。
- 返回 `fee`、`standard`、`membership`、`payment_connected`，金额单位为分 R。
- 账户专属价优先，包含显式设置的零元价格；否则按有效会员等级折扣计算，四舍五入到分。
- 套餐不存在、已下架或参数缺失返回 404，未登录返回 401。金额仅取自数据库。

报价复用 `membership_for` 和 `fee_for`，与会员页、服务目录计价保持一致。不创建订单、冻结余额或发送上游付款请求。付款可用性仍与公开目录保持为 false，本次不接入执行流程。

修改订阅模块仅用于移除重复的报价路由，保留其余已有代码。旧整体验收中的执行后端缺失断言不适用于磁盘上其他新增的订阅实现；本次针对报价、鉴权和会员逻辑验证。

验证完成：4 组针对性集成测试通过（报价、会员、鉴权、现有读取接口），使用 18972 上的独立临时数据库并清理。覆盖折扣取整、专属价含零元、会员到期、账户隔离、下架及不存在套餐、API 密钥和报价不变更余额/订单/账本。18970 本地服务已重启，存活/就绪检查通过，4 个上架套餐报价均返回 200；浏览器订阅页面显示当前账户报价 10.00 R，原错误提示消失。未提交真实订阅或付款。
