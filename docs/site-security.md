# 站点功能、邮箱与认证

后台「站点设置」新增功能开关、安全与认证、邮件设置。升级默认开放所有现有客户功能，保持当前自主注册状态，邮箱验证和邮件服务默认关闭；管理员配置 SMTP 并测试后可开启验证。不会复制其他项目的邮件凭据。

## 功能权限

`features` 控制工作台、订阅办理、订单中心、资金账户、结账链接、续费管理、开发接入、伙伴计划、会员中心、API 文档。个人设置保留。服务端 `/api/me` 只返回开放的客户菜单，客户首页与个人设置同步移除关闭模块的入口和数据。

受理前校验覆盖网页登录、用户 API、三个订阅入口及 Session 检查。开发接入关闭后，已有密钥及 `/api/v1/*` 访问暂停。订单中心关闭后不允许查询订单列表、详情与进度；订阅/链接创建开关独立控制新请求。关闭功能不终止已受理的任务，不改变会员计价、邀请结算或付款执行。会员、资金、订单数据不会从账户概要旁路返回；报价仍返回本次服务费。

管理员菜单独立到需管理员会话的 `AdminChrome` 资源，管理页面及其样式资源也校验权限。普通客户响应不包含管理菜单。所有管理接口仍要求管理员身份；API 密钥不得调用管理接口。文件名、路径不作为安全边界，真正授权在服务端。

## 注册与找回密码

安全设置中的开放注册同步原 `site.registration_open`，保持旧客户端兼容且不形成两个独立开关。域名白名单为空允许全部；精确域名仅匹配本域，`*.example.com` 匹配本域及子域。规则只约束新注册，不影响已有用户找回密码。

`POST /api/auth/email-code` 接受 `email` 和 `purpose`（`register`/`reset`）。六位验证码有效 15 分钟，60 秒发送冷却，最多 5 次错误验证；每 IP 每分钟 5 次、每日 100 次发送请求，每邮箱每日最多 20 次。验证码按邮箱和用途绑定，HMAC 保存。发送返回统一结果，邮箱不存在/已注册/停用不暴露账号存在性；发信由后台任务执行，结果记录在后台邮件记录。只有 SMTP 接受发送的验证码可用。

注册提交 `/api/auth/register`，启用验证时须附 `code`，消费验证码与创建用户同事务。`POST /api/auth/reset-password` 接受 `email`、`code`、`password`。重置凭据同时绑定当前用户与密码状态，事务锁保证并发仅一次成功。成功后撤销所有登录会话和 API 密钥。未验证邮箱的旧用户也可通过对应注册邮箱证明所有权；管理员仍可从账户管理维护用户。

## 邮件管理

配置 SMTP 主机、端口、用户名、授权码/密码、发件邮箱、发件名以及 SSL/TLS 或 STARTTLS。TLS 验证服务器证书，不允许明文认证。密码使用现有主密钥加密保存，读取配置不回传明文或密文；空密码保留原值，清除需显式选中。不能在注册邮箱验证仍开启时停用邮件。

测试发送仅管理员可用且限流，使用已保存配置。发送记录保留 90 天，显示收件地址、用途、时间、SMTP 接受/失败状态和安全错误摘要；不记录验证码或正文。已发送不表示收件人一定收到，请结合测试邮箱及供应商记录排查。失败或进程中断的发送需用户重新获取，不后台重发过期验证码。

本地验收使用一次性数据库、调度 mock 和测试 SMTP，不启动已迁移的本机业务应用，也不向真实用户发送邮件。

## 账户删除

账户管理支持逐个 DELETE `/api/admin/users/{id}` 和批量 POST `/api/admin/users/batch-delete`（`ids`，最多500个）。确认后从账户管理及会员管理移除，账号归档停用、清空密码哈希、撤销会话和 API 密钥、清理注册/重置验证码；历史订单、资金、邀请及审计引用保留，已受理任务继续执行。不撤销既有结算或释放仍在任务中的冻结资金。

同一邮箱可重新注册，新账号使用新ID，不继承旧余额、订单、会员或邀请关系。有效邮箱唯一索引只覆盖未删除用户；登录、邮件验证和邀请标识检索排除已删除记录。旧后台编辑、调账、会员及定价入口不能恢复已删除账号。批量结果返回成功数量及被保护账户的原因；重复删除不重复审计。当前登录的管理员和最后一个可用管理员受到服务端保护。

## 自定义菜单

站点设置 → 自定义菜单，支持最多30项，列表顺序即导航顺序。每项配置名称、HTTP/HTTPS URL、静态SVG图标、可见角色（普通用户/管理员/所有登录用户）、启用、新窗口打开及隐藏嵌入页新窗口按钮。管理员菜单出现在管理侧边栏；用户菜单出现在客户侧边栏。保存才生效，默认列表为空。

网页 `/api/me.custom_menus` 只返回当前角色可见且启用的菜单；匿名公开资料不下发菜单，管理配置仍仅管理员可读写。`GET /api/custom-pages/{id}` 再次按角色验证，不存在、禁用和不可见均404；匿名401，API密钥不能调用网页菜单接口。既有v1用户接口及文档协议不变。

管理员继承普通用户菜单的查看权限，在客户工作台也能看到“普通用户”菜单；“管理员”菜单仍只下发给管理员。此规则不修改已保存的菜单配置、顺序或打开方式，禁用菜单对所有角色均不可访问。

新窗口链接带noopener/noreferrer，不附加用户或令牌；站内页面使用隔离iframe，no-referrer，不能导航顶层窗口，同源页面不授予allow-same-origin。仅放宽CSP的frame-src至HTTP/HTTPS，脚本来源限制保留。目标站不允许嵌入时应选择新窗口模式；平台不代理外部页面。SVG作为图片渲染，服务端拒绝脚本、事件、外部引用、DTD及动态内容。

## 站点图标

品牌与服务支持上传PNG（256KB以内、16～1024像素）或静态SVG（20KB以内），预览后随“保存配置”生效，可恢复序付默认图标。图标在浏览器标签页、登录页、工作台及接口文档品牌处统一使用；默认深蓝/薄荷绿叠层图标随应用内置，旧配置无需修改即可显示。

自定义图标以data URL保存在site.icon，仅管理配置返回原内容；公开site资料只给带内容版本的icon_url，`/site-icon`及兼容`/favicon.ico`匿名返回图像。响应使用明确图片类型与nosniff，沿用no-store避免旧图标缓存；页面保存后更新版本URL。服务端验证类型、大小、PNG尺寸/块校验及SVG静态内容，拒绝外部图标地址、脚本/事件/DTD等。旧表单省略icon字段时保留原图标，空字符串恢复默认；不增加文件上传目录或数据库结构。
