# 国家代理池与订阅地区

代理管理提供手动代理和国家代理池两个独立标签页。`settings.proxy.mode` 缺省为 `manual`，上线不自动切换。后端在分配、重试和模式切换时执行互斥检查；切换使用现有调度、续费和代理锁。正在办理、需要沿用原绑定恢复的任务及检测租约未结束时拒绝切换，未绑定的排队订单先校验目标模式的国家支持。

## IPRoyal

国家代理池使用官方 `https://resi-api.iproyal.com/v1`：`GET /access/countries` 同步账户可用国家，`POST /access/generate-proxy-list` 按单生成 `rotation=sticky`、单一 `_country-` 和配置有效期的连接。优先使用等价的小时/分钟表示有效期（真实 API 不接受 `3600s`，接受 `1h`）。连接、国家和会话字段必须符合响应约束；未知响应、认证失败和国家不匹配不会转用手动代理。生成和分配按当前供应商规则执行，不添加出口探测、IP 去重或供应商切换策略。

令牌与代理密码使用平台主密钥加密，独立配置不经过通用 settings 接口回显；管理员可以从已有 IPRoyal 手动代理复制基础账号和有效期。供应商参数不会当作基础密码保存。手动代理完整地址按管理员要求在资源列表和编辑表单显示，仅管理员接口可读取；不会出现在普通客户、开放 API 或日志中。

每个订单第一次执行时持久化加密代理地址、来源模式、供应商会话和到期时间。重复领取读取原绑定；过期停止，不延长时长。供应商返回的会话标识通过数据库唯一表检查，避免不同订单复用同一会话，但独立会话不等于供应商承诺出口 IP 永不重复。账号 Session 刷新不更换代理。独立续费任务在国家代理池模式下也固定会话，后续核实复用，过期转待核实。

手动 IPRoyal 动态代理是可按国家使用的模板：选取时不受资源原国家限制，订单分配时替换 `_country-`，生成独立 session，并保留原 lifetime 规则。静态及其他厂商维持原匹配与会话规则。修改模板不更改历史订单已保存的连接。

## 国家与币种

`backend/data/country-currencies.json` 是 2026-11-06 从用户指定 GPT Pay 充值页面的目录接口提取的 248 个国家和币种配置，不代表逐国真实付款验证。当前 IPRoyal 账户返回的 202 个国家全部可匹配。地区币种可在后台修改；金额展示按对应币种小数位处理，服务费仍为积分。

同步保留已有地区名称、币种、排序和启停，新国家默认关闭；管理员可筛选、编辑和批量开放。删除的地区记录同步抑制标识，后续同步不会恢复。失败保留上次成功国家库；自动同步每天最多尝试一次，独立后台执行。供应商移除国家时，国家代理池模式下不再向客户提供该国家；原订单保存的快照不变。

当前 `cslive_go_direct_pay` 支持动态地区；旧流程仍使用原七地区及原币种。开放地区需有效币种并符合流程，国家代理池模式还需供应商支持。手动模式保留原地区开放规则；管理员列表提示是否配置代理（IPRoyal 动态模板支持按国家替换）。

客户网页和 `GET /api/v1/catalog` 使用相同目录，`POST /api/v1/orders.country` 从 `countries[].code` 获取。订单受理后保留地区和币种快照。接口不接受供应商凭据、会话或币种覆盖。

## 验证

新增数据库集成测试覆盖模式互斥、并发领取同单、跨单会话去重、过期、国家校验、禁止回退、容量等待、国家同步保留人工配置、删除不恢复、管理员权限及脱敏、独立续费、手动模板跨国家和完整地址回显。前端金额测试覆盖 PHP、JPY、XPF、OMR、BHD、KWD。真实供应商联调仅生成粘性代理，没有发起付款或账号操作。
