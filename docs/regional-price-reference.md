# 地区套餐参考价格

订阅办理与结账链接页面增加“各国订阅价格”。国家选择按当前套餐的 R 参考金额升序排列，同时显示当地月费及币种。Team 按当前普通/高级席位计算总额；价格表单独展示每席位价格。缺少报价、汇率或所配置结算币种不符时不编造零价，排到已知报价之后。平台服务费仍为积分。

后台“订阅地区 → 地区价格定时配置”可保存价格/汇率独立开关及间隔，默认分别每1小时、每天1次；支持立即安排更新和查看进度、失败原因。查询范围为订阅地区当前所有记录（包括未开放地区），新增自动采集，删除立即从返回结果移除。付款开关不影响参考数据调度。

价格只由服务器访问 ChatGPT 匿名地区配置接口 `https://chatgpt.com/backend-anon/checkout_pricing_config/configs/{COUNTRY}`。套餐映射为 plus/plus、pro5x/prolite、pro20x/pro、pro50x/promax、Team普通/business、高级/business_prolite；原应用 pro/promax 对应 Pro20x/Pro50x。仅接受地区代码一致、有效货币和正有限月费；单位已经是主货币单位，包括JPY，不再除以100。有明确税前支付通道覆盖价时展示该价，同时保留官网含税金额与来源时间；不自行推算税率。参考价不替代实际结账，未知套餐不自动映射。

服务器每日访问 `https://open.er-api.com/v6/latest/CNY`，校验基准和发布时间并将汇率倒数转成外币→R。页面保留 ExchangeRate-API 主页署名链接，不向用户返回实际上游 API 地址、请求参数、错误正文或凭据。此公共报价来源是网站实现接口，覆盖与可用性可能变化，不承诺所有地区都有报价。

`GET /api/subscription-prices` 仅登录用户且开放订阅/提链功能时可读本站缓存；不会触发外部采集。价格表刷新也只重新读取本站快照。管理配置 `/api/admin/region-prices` 及 `/refresh` 强制管理员权限。全量来源地址仅在后端实现和此维护文档中，前端构建资源不包含它们。

缓存存于 settings 的 regional_price_schedule / regional_price_cache / regional_fx_cache，持久化跨重启。每个短批次最多两地区，每地区一次获得全部套餐；跨进程事务锁防重复，HTTP有超时和响应体上限。403/429全局退避15分钟；其他失败按配置间隔重试，保留原成功数据与时间。无变化不重复写缓存。手动更新60秒合并，不能绕过来源冷却。用户请求不会生成支付会话、不使用用户Session或订单代理、不发起付款。

验证包括匿名源实际PH/EG/JP/US请求、货币单位/税费、独立定时、地区增删、旧值保留与冷却、重复调度互斥、权限和无上游地址泄露、套餐切换/Team席位排序与缺失值、桌面/390px布局。原付款、代理绑定和费用结算逻辑保持。
